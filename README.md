# vasylian.com — portfolio of Artur Vasilyan

Static site, no framework: HTML generated once per language, one stylesheet, one script.
GSAP and the QR library come from cdnjs; fonts from Google Fonts (Playfair Display + Inter).

## What is on the page

- **8 full language versions** — English at `/`, then `/lv/ /lt/ /ee/ /pl/ /de/ /ua/ /ru/` (hreflang, sitemap, OG image per language).
  Swedish, Finnish, Danish, Dutch, French and Spanish get the first screen only, swapped in place.
- **37 projects**: 4 client sites (Ventsistema, Autopalīdzība, Vārtu pasaule — live; Kimela — launching) and 33 concepts,
  plus "beyond homepages" (Paceļam, the SOS app, Manufaktura Czasu).
- Filters by country and trade, a dot map of Europe (tap a country to filter), a project sheet with laptop + phone screenshots
  and the **real page inside a phone**, before/after sliders, a receipt-style price, FAQ, and an email composer.
- Language pages put their own country's projects first.

## Personal links for cold emails

Add `?c=<project id>` to any language page and the owner is greeted by name, with their concept pinned first:

```
https://vasylian.com/lv/?c=krio
https://vasylian.com/lt/?c=bliekorius
https://vasylian.com/pl/?c=romian
```

Filters also live in the URL: `https://vasylian.com/lt/?cc=LT&t=build#work` (countries `LV LT EE PL UA AT SE`,
trades `build systems interior auto care venue`). Project ids are the `id` fields in `_src/works.cjs`.

## Adding a project

1. Add an entry to `_src/works.cjs` (id, kind, name, city, cc, geo, trade, url, craft and tag in 8 languages).
2. Add its URL to `_src/targets.json` and capture screenshots:
   ```
   NODE_USE_ENV_PROXY=1 NODE_PATH=$(npm root -g) node _src/capture.cjs <id>
   python3 _src/shots.py <id>          # PNG → assets/shots/<id>-d.webp, -d-640.webp, -m.webp  (needs Pillow)
   ```
3. Rebuild: `node _src/build.cjs` — rewrites every `index.html`, `sitemap.xml`, `robots.txt` and `404.html`.
   Counts ("37 sites", "7 countries", per-country chips, the map) are computed from the list.

Before/after pairs need `<id>-old-m.webp` (capture `<id>-old` from the client's old site) and the id in `pairs` in `build.cjs`.

## Changing text

All copy is in `_src/i18n/<lang>.cjs` (same keys everywhere; a missing key falls back to English).
`*word*` marks the orange italic accent. Run `node _src/build.cjs` afterwards.

Social images: serve the folder (`npx http-server -p 8080 .`) and run `node _src/og.cjs` (same env as capture).
The dot map is generated by `python3 _src/map.py` from Natural Earth data (`world-atlas`).

## Deploying

This repo builds to plain files, so GitHub Pages can serve it from the branch root.
The domain vasylian.com is currently attached to `vasilyanaptyp-oss.github.io`; to make this the live site,
copy the generated files there (or move the custom domain to this repo). All asset paths are relative,
so the site also works from a sub-path such as `/vasylian/`.
